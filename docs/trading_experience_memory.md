# Nova Trading Experience Memory

Nova's memory is trading experience, not generic assistant memory.

The trade journal must preserve both decision context and execution experience.
For future MT5 DEMO observations, a trade record should retain strategy/version, market state, explicit approval, order status, requested versus executed price, execution latency, slippage, final outcome, exit reason, and timestamps.

These fields describe what happened. They do not authorize execution or promote a strategy.
Research evidence remains immutable; trade outcomes may transition from OPEN to a closed outcome.
